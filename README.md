# portfolio-murayama-260206

## 概要

このプロダクトは、私が以前からpixi.jsを使用して自作している2Dゲームです。

未完成ですが、マップスクロールやフラグ、アニメーション制御部は自分で構築することを目標としています。

以前は自宅のPCをサーバー化し、apache, DNSを使用して外部ネットワークからアクセスできる状況を作っておりました。

## 起動方法

1. パッケージをダウンロード
2. ディレクトリをportfolio-murayama-260206に移動<br>
例: cd Downloads/portfolio-murayama-260206
3. ローカルサーバーを起動<br>
python3 を使用した例: python -m http.server 8888
4. ブラウザで`http://localhost:8888/`にアクセス

## 操作方法

- 移動：十字キーで移動ができます。斜め移動入力も受け付けています。
- 攻撃：Dキーで攻撃します。墓石のオブジェクトは二回で破壊可能です。
- オブジェクトを調べる：Aキーで調査可能。右上側の墓石にはテキスト表示機能を実装しています。
- テキストボックスを読み進める：スペースキーで次のテキストに読み進められます。

## ファイル構成

- assets/events/\*.json:
  マップ上の個別オブジェクトのイベントを記載しています。
- assets/LargeMapTest.json
  マップ上の要素配置やイベント、当たり判定を記載しています。
- img
  画像ファイルの格納場所です。
- js/GameObject.js
  マップ上のオブジェクトのクラスです。座標や被攻撃時の挙動を取り扱っています。
- js/main.js
  ゲーム画面の大半がこのファイルに記載されています。画像表示やアニメーション、マップスクロール、移動など
- js/NpcObject.js
  NPCのクラスです。移動時のアニメーションが示されています。（このファイルは特に増やすべき機能が多いです）
- js/pixi.min.js
  使用しているライブラリである、pixi.jsの実体です。
- game.html
  ゲーム用のWebページです。スタイルやWebページとしてのUIは未実装です。
- index.html
  game.htmlにポーティングするだけのindexファイルです。
